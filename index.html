PagedAttention 原理与具体实现

Posted on 2026-07-07 Edited on 2026-08-07 In 大模型

KV Cache的内存管理困境

KV Cache 的大小会随着序列长度和并发请求数迅速增长。以 OPT-13B 模型为例，单个 token 的 KV Cache 占用约 800KB（2 × 5120 × 40 × 2 bytes）。若生成完整的 2048 个 token，单个请求的 KV Cache 就高达约 1.6GB。而且在 Parallel Sampling 或 Beam Search 等场景中，多个生成分支共享相同的 prompt，理论上可以共享其 KV Cache。然而传统系统将每个分支的 KV Cache 存放在独立连续空间中，物理上无法共享，只能冗余复制。

大模型推理的"加速引擎"：从 QKV 到 KV Cache

Posted on 2026-07-07 Edited on 2026-08-07 In 大模型

Attention 机制的基石：QKV

QKV 是 Transformer 架构中 Attention 机制的核心三要素，分别代表 Query（查询）、Key（键） 和 Value（值）。

一个经典的类比是图书检索系统：

  • Query（查询）：你在图书馆检索时输入的关键词。它表达了”我想找什么”。
  • Key（键）：图书的索引标签或标题。它描述了”每本书是关于什么的”。
  • Value（值）：图书的实际内容。它是系统最终要返回给你的”有用信息”。

在 Transformer 中，每个输入 Token 都会通过三个不同的线性变换矩阵（(W_Q, W_K, W_V)）分别生成其对应的 Q、K、V 向量。注意，同一个 Token 的 Q、K、V 是不同的，它们服务于不同的目的：Q 用于”询问”，K 用于”被匹配”，V 用于”提供内容”。

SFT

监督微调（Supervised Fine-Tuning, SFT） 的核心，就是使用预先验证过的、带标签的数据，来让一个已经预训练好的大语言模型（LLM）适应特定的下游任务。

简单来说，SFT就是在预训练模型的基础上，用标注好的“问题-答案”数据，进行一次有监督的训练。

参数高效微调（PEFT）

大语言模型（如 LLaMA、GPT）动辄数十亿甚至千亿参数，全量微调的成本极高。以 65B 模型为例，仅以 FP16 精度加载就需要约 130GB 显存，顶配硬件跑个几天几周是常有的事。

参数高效微调（PEFT）方法应运而生——只更新一小部分参数，效果却不输全量微调。LoRA 和 QLoRA 正是其中的代表。
